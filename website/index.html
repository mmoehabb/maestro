01

A worktree for every idea.

Run a fix, a feature, and a refactor side by side. Each task gets its own Git worktree and branch, so agents can work without stepping on each other’s changes.

02

Change agents. Keep the thread.

Hand a task to another agent with its goal, notes, recent conversation, and Git state. Return to a previous agent and resume its own saved session.

03

Pick up where you left off.

Quit, come back, and restore your task tabs. Session identities and history stay saved, with native conversation import for Codex, agy, and OpenCode.

04

From first prompt to pull request.

Push your branch, create a pull request on GitHub, GitLab, or Codeberg, follow CI and reviews, then merge and clean up—all from the same workspace.

03 / Find your rhythm

You set the tempo.

A familiar terminal workflow,
with room for the whole ensemble.

  1. 1

    Give an idea its own space.

    Name your task, choose an agent, and give it a prompt. Maestro prepares an isolated worktree.

    maestro new "Fix login" -a codex
  2. 2

    Conduct the work.

    Move between tasks, check progress, or hand off to a different agent when you want a fresh approach.

    prefix + aswitch agent
  3. 3

    Bring it home.

    Review the changes, open a pull request, and merge. Archive the task with its history preserved.

    prefix + Pcreate / open PR

Your prefix is ctrl+m in terminals with keyboard disambiguation, or ctrl+b otherwise. prefix ? shows all shortcuts.

01

Install Maestro

From source with Go 1.26+. Make sure your Go binary directory (usually ~/go/bin) is on your PATH.

go install github.com/mmoehabb/maestro/cmd/maestro@latest
02

Set the stage

Install and authenticate at least one supported agent CLI separately. In a Git checkout with at least one commit, check your setup:

maestro doctor
03

Start your first session

Create a task, then open Maestro to launch the agent. Use an agent you have installed; this example uses Codex.

maestro new "Fix login" -a codex -p "Repair the login flow"
maestro

Using GitHub, GitLab, or Codeberg PR features? Authenticate with gh auth login, glab auth login, or tea login add (or token environment variables). Using Kimi Code? Enter your prompt inside the agent pane instead of using -p.
